# Laundress Bot - «Стиралка»

Telegram-бот для записи на стиральные машины и сушилки в общежитии.

Бот помогает жильцам быстро выбрать свободную дату, машину и время, а администраторам — смотреть расписание, управлять записями, импортировать и экспортировать данные.

## Возможности

### Для пользователей

- регистрация по фамилии и номеру комнаты;
- запись на стиральную машину или сушилку;
- просмотр свободных слотов по датам и машинам;
- ограничение: одна запись на стирку и одна запись на сушку в сутки;
- просмотр своих активных записей;
- отмена записи;
- автоматическое предложение сушилки после записи на стирку;
- напоминание за 30 минут до записи;
- редактирование фамилии и комнаты через `/edit`.

### Для администраторов

- просмотр расписания по дням;
- удаление записей;
- бан и разбан пользователей;
- просмотр списка заблокированных пользователей;
- экспорт записей в Excel;
- импорт записей из Excel;
- ручное создание записи по фамилии и комнате;
- включение и выключение отдельных машин;
- уведомление пользователей с незаполненным профилем;
- тестирование напоминаний.

## Стек

- Python
- aiogram 3
- aiohttp
- APScheduler
- SQLite для локального запуска
- PostgreSQL через `DATABASE_URL` для деплоя
- pandas и openpyxl для импорта/экспорта Excel
- Render / любой сервер с webhook-запуском

## Структура проекта

```text
laundress-bot/
├── bot.py                  # локальный запуск через polling
├── webhook_app.py          # запуск через webhook, например на Render
├── config.py               # настройки бота, машин, времени и БД
├── database.py             # работа с SQLite/PostgreSQL
├── scheduler.py            # напоминания и фоновые задачи
├── keyboards.py            # клавиатуры Telegram
├── requirements.txt        # зависимости
└── handlers/
    ├── registration.py     # регистрация и редактирование профиля
    ├── booking.py          # запись, отмена, мои записи
    └── admin.py            # админ-панель и админ-команды
```

## Команды пользователя

| Команда | Описание |
|---|---|
| `/start` | Запуск бота и регистрация |
| `/book` | Записаться на стирку или сушку |
| `/mybookings` | Посмотреть свои активные записи |
| `/cancel` | Отменить активную запись |
| `/edit` | Изменить фамилию и номер комнаты |
| `/help` | Помощь по использованию бота |

Также доступны кнопки главного меню:

- `🧺 Записаться`
- `📋 Мои записи`
- `❌ Отменить запись`
- `ℹ️ Помощь`

## Команды администратора

| Команда | Описание |
|---|---|
| `/admin` | Открыть админ-панель |
| `/export` | Экспортировать записи в Excel |
| `/import` | Импортировать записи из Excel |
| `/machines` | Посмотреть машины и включить/выключить их |
| `/ban` | Заблокировать пользователя |
| `/unban` | Разблокировать пользователя |
| `/banned` | Посмотреть список заблокированных |
| `/abookfio` | Создать запись вручную по фамилии и комнате |
| `/notify_incomplete` | Напомнить пользователям заполнить профиль |
| `/test_reminder` | Проверить работу напоминаний |

Формат ручной записи:

```text
/abookfio <Фамилия> <Комната> <machine_id> <YYYY-MM-DD> <HH> [комментарий]
```

Пример:

```text
/abookfio Иванов 412 3 2026-07-10 19 после пары
```

## Настройка

Основные настройки находятся в `config.py`.

```python
TIMEZONE = "Europe/Moscow"

BOT_TOKEN = os.getenv("BOT_TOKEN")

WASHING_MACHINES = [
    "Стиральная №1",
    "Стиральная №3",
    "Стиральная №5",
    "Стиральная №6",
]

DRYERS = [
    "Сушилка №2",
    "Сушилка №4",
]

WORKING_HOURS = list(range(7, 23))
BOOKING_DAYS_AHEAD = 3
DB_PATH = "laundry.db"
```

### Как добавить новую машину

Нужно добавить название в один из списков в `config.py`.

Для стиральной машины:

```python
WASHING_MACHINES = [
    "Стиральная №1",
    "Стиральная №3",
    "Стиральная №5",
    "Стиральная №6",
    "Стиральная №7",
]
```

Для сушилки:

```python
DRYERS = [
    "Сушилка №2",
    "Сушилка №4",
    "Сушилка №8",
]
```

При webhook-запуске бот добавляет машины из конфига в базу при старте. Уже существующие машины не дублируются.

Если машина временно не работает, её не нужно удалять из базы. Администратор может открыть `/machines` и выключить её — она пропадёт из записи, но старые записи и история сохранятся.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---:|---|
| `BOT_TOKEN` | Да | Токен Telegram-бота от BotFather |
| `DATABASE_URL` | Нет | URL PostgreSQL. Если не задан, используется SQLite |
| `RENDER_EXTERNAL_URL` | Для Render | Внешний URL сервиса на Render |
| `WEBHOOK_BASE_URL` | Для webhook | Базовый URL сервиса, если запуск не на Render |
| `PORT` | Нет | Порт для `webhook_app.py`, по умолчанию `10000` |

## Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ilyinmax/laundress-bot.git
cd laundress-bot
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
```

Активировать окружение:

```bash
# Linux / macOS
source .venv/bin/activate
```

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Задать токен бота

Linux / macOS:

```bash
export BOT_TOKEN="your_telegram_bot_token"
```

Windows PowerShell:

```powershell
$env:BOT_TOKEN="your_telegram_bot_token"
```

### 5. Запустить бота

```bash
python bot.py
```

При локальном запуске будет использоваться SQLite-база `laundry.db`.

## Запуск через webhook

Для серверного запуска используется файл `webhook_app.py`.

Пример команды запуска:

```bash
python webhook_app.py
```

Для webhook-запуска должны быть заданы:

```bash
BOT_TOKEN=your_telegram_bot_token
WEBHOOK_BASE_URL=https://your-domain.example.com
```

Если проект запущен на Render, вместо `WEBHOOK_BASE_URL` можно использовать автоматическую переменную `RENDER_EXTERNAL_URL`.

Проверка работоспособности:

```text
GET /health
```

Бот принимает Telegram webhook по адресу:

```text
/webhook
```

## Деплой на Render

Пример настроек Render:

```text
Build command:
pip install -r requirements.txt

Start command:
python webhook_app.py
```

Переменные окружения:

```text
BOT_TOKEN=<токен Telegram-бота>
DATABASE_URL=<строка подключения PostgreSQL>
```

`RENDER_EXTERNAL_URL` Render обычно задаёт автоматически. Если переменная недоступна, нужно вручную добавить:

```text
WEBHOOK_BASE_URL=https://<адрес-сервиса-на-render>
```

## База данных

Бот автоматически создаёт нужные таблицы при запуске.

Используются таблицы:

- `users` — пользователи;
- `machines` — стиральные машины и сушилки;
- `bookings` — записи;
- `banned` — заблокированные пользователи;
- `failed_attempts` — неудачные попытки регистрации;
- `reminders_sent` — защита от повторных напоминаний.

Если переменная `DATABASE_URL` задана, используется PostgreSQL. Если не задана — локальный SQLite-файл `laundry.db`.

## Excel-импорт

Администратор может выполнить команду:

```text
/import
```

После этого нужно отправить `.xlsx`-файл с колонками:

```text
Дата
Час
Машина
Фамилия
Комната
```

Бот создаст записи, а некорректные или занятые слоты пропустит.

## Excel-экспорт

Команда:

```text
/export
```

Бот сформирует `.xlsx`-файл со всеми записями.

## Правила записи

- пользователь должен пройти регистрацию;
- прошедшие часы скрываются;
- занятые слоты отображаются как недоступные;
- нельзя занять уже занятый слот;
- в один день можно иметь одну запись на стиральную машину и одну запись на сушилку;
- после записи на стирку бот может предложить свободную сушилку на следующий час;
- напоминание отправляется за 30 минут до записи.

## Безопасность

- токен Telegram-бота нельзя хранить в коде;
- `BOT_TOKEN` нужно передавать через переменные окружения;
- локальную базу `laundry.db` не стоит коммитить в репозиторий;
- файлы окружения вроде `.env` нужно добавить в `.gitignore`;
- доступ к админ-командам проверяется по Telegram ID администратора.
